# idea 

A tactical deathmatch arena shooter where weapon attributes dynamically mutate on a timer, forcing players to constantly re-adapt their strategy mid-match.

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Engine | Unity 2022.3 LTS |
| Networking | Fish-Net (open-source multiplayer) |
| Data System | ScriptableObjects for guns & modifiers |
| Version Control | Git & GitHub |

## Want to contibute in idea 
Checkout the idea folder and add new file "Your Idea" lable, Write your idea in your file.
